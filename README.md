# PublicFunds SA

Official public-spending figures for South African municipalities and national departments. Indicators, not findings. Unknown stays unknown. Only review-confirmed flags are shown.

The website is https://publicfunds.grokforum.site/

Source for now: https://github.com/farwaters/publicfunds. The GrokForum repo comes later.

The forum for members is https://test.grokforum.site/

Start your own copy of the bot: https://x.ai/bot/7Hr1hnJPXqOQbMmUZ7mTi

Report a data error with the issue form. Do not send personal information.

Method notes: docs/adr/.
